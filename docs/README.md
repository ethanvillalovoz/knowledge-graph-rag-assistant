# Documentation

This directory contains the maintained research documentation and the
historical record of the Knowledge Graph RAG Assistant senior design capstone,
originally developed under the ACME10-HE-RAGApp name.

## Current research documentation

- `paper/` - publication-style technical report and its scope statement.
- `REPRODUCIBILITY.md` - code, artifact, external-service, and paper-snapshot boundaries.
- `benchmarking.md` - guidance for interpreting recorded timing and evaluation material.
- `demo-strategy.md` - provenance and labeling requirements for demonstration media.
- `performance-stats.md` - runtime notes preserved from development.

## Historical capstone record

- `project-report/` - final report, abstract, traceability matrix, prototype report, and final client presentation.
- `sprint-reports/` - sprint reports and sprint presentation decks.
- `meeting-notes/` - client and team meeting notes.
- `code-guides/` - notebooks used to explore knowledge graphs, BERT embeddings, and FAISS vector search.
- `images/` - project and team images.

For setup and usage instructions, see the root [README](../README.md). Data and
media rights are described separately in [Data Notice](../DATA_NOTICE.md) and
[Asset Sources](../ASSET_SOURCES.md).
