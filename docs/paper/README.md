# Technical report

`knowledge-graph-rag-technical-report.pdf` is the publication-style adaptation
of the team's April 2025 capstone report. It presents the preserved capstone
system as a technical report; it does not add a comparative retrieval
benchmark, answer-quality evaluation, or production-reliability claim.

The report's implementation evidence is anchored to repository commit
[`1ad5cc0`](https://github.com/ethanvillalovoz/knowledge-graph-rag-assistant/tree/1ad5cc08cbebdeae655cad626393364b2f476556).
The current `main` branch is maintained separately and may contain later
documentation, interface, dependency, and safety changes.
